NEWBRIDGE CAMPUS CONNECT
VPPHX classroom website project — content included through 4 August

HOW TO OPEN THE WEBSITE
1. Keep all folders and files together.
2. Open index.html in a web browser.
3. Use the navigation links to move between the four pages.

PAGES
- index.html: Homepage
- programmes.html: Programme cards, data attributes, events and a table
- student-life.html: Images, audio, video and global attributes
- contact.html: A complete demonstration form

FILES AND FOLDERS
- styles.css controls the colours, spacing and layout.
- script.js controls the simple interactions.
- images contains the image files.
- media contains the audio and video files.

SCOPE INCLUDED
- HTML structure, syntax, character encoding, CSS and JavaScript links
- Headings, paragraphs and text formatting
- Ordered and unordered lists
- Tables
- Images and hyperlinks
- Audio and video
- Forms
- Styling and layout
- Global attributes
- Event and data attributes

04 AUGUST ADDITIONS
- programmes.html contains a clearly labelled classroom demonstration panel.
- Internal CSS appears inside the <style> element in programmes.html.
- Inline CSS appears on the information-session date inside a <span>.
- Named, hexadecimal and RGB colours are demonstrated and commented.
- Font family, size, weight and style are demonstrated and commented.
- <div> and <span> examples explain block and inline grouping.
- id, class, title, lang, dir, translate, hidden and accesskey are labelled.
- onclick, onmouseover, onmouseout, onkeyup, oninput and onsubmit are identified.
- data-* attributes on programme cards and the lesson panel are explained.
- styles.css and script.js contain additional comments linking the code to the lesson.

The website intentionally does not introduce the topics scheduled after
4 August. Those can be added gradually with the class.

IMPORTANT
This is an educational redesign concept. It is not the official Newbridge
Graduate Institute website, and the enquiry form does not send real data.
